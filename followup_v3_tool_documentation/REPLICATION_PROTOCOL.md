# Independent checkpoint replication of the tool coverage test

This local plan was written after all Qwen results were known and before running the 512 scope cards on SmolLM2. The earlier BlueDot experiment informed availability of a complete SmolLM2 checkpoint; it did not use these tools. The workflow does not select a second model based on its results on the scope task.

Use the original SmolLM2-1.7B-Instruct checkpoint at revision 31b70e2e869a7173562077fd711b654946d38674. Recover the exact system and user message text for every inline card in the existing 512-card Qwen transfer. Let the SmolLM2 tokenizer supply its chat template. Verify that neither message body changes. Use a fresh context for each prompt, float32 on MPS, greedy generation, the model's EOS, a maximum of 72 new tokens, no stop rules based on response, and no tools attached. Use the archived response parser without any changes. Record full text, token IDs, first EOS or cap, identities and model/file hashes. Count every capped and other response, and list all observed output formats. Never remove a card to improve compliance.

Primary estimate for each independent checkpoint: office-only minus neither-matches attempted-call proportion, paired within the same tool, target district, vocabulary and field ordering, then averaged over 128 matched pairs. Report forward and reverse transitions and counts separately by vocabulary and order (32 pairs per stratum), and differences in these descriptive proportions across the two fixed checkpoints. Include in-scope exact calls, inapplicable literal abstentions, invalid and unclassified outputs, and a sensitivity endpoint using only exact function-and-arguments JSON over the same entire denominator. A model always calling or never making valid calls would be uninformative about field selectivity; present this as a measurement limitation. Eight tools share their template, so the denominators describe the constructed bank, not a population of independently sampled real tools. No layer selection, new prompt tuning or claim about SmolLM2 activations. Freeze the plan and runner hashes at launch.
