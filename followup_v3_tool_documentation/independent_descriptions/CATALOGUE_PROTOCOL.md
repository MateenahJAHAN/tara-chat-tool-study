# Can an incidental office address trigger error in a multi-tool catalogue?

The original TARA paper changed a documentation-office address on locally authored cards. This companion to the single-tool run holds a real user question and externally written function descriptions fixed. Only the catalogue's documentation-office city changes within a pair. The office sentence and experiment instructions are written for this intervention. The function descriptions, input schemas and questions remain external.

Use every question in the frozen external bank with one explicitly named city in the list in build_catalogue.py. The matching header uses that city. Mismatch cities are reassigned by a cyclic permutation with zero fixed points, so city frequency is identical across arms. Each question is shown with all its eligible tools, then with its unique reference tool removed. Catalogue order is fixed by hashing question and tool name and preserved across conditions. One to seven distractors can remain. Both models receive all four cells. Conditions are generated with deterministic inference using 96 output tokens, identical checkpoints and hardware settings as the single-tool study. The tool call is simulated.

Primary endpoint: among target-absent catalogues, how many question pairs switch from abstention/non-call to attempted call when only the office changes from mismatched to matched, and how many switch in the reverse direction? Report exact abstentions and unclassified replies. The companion positive endpoint counts correctly selected reference names with argument objects, and their gains/losses, when the correct tool is present. Describe the paired changes with counts and an exact McNemar test if there are discordant pairs. A zero contrast on a saturated endpoint leaves little information about the office cue. This intervention tests action selection, not a mechanistic localization or the system's ability to perform the action.

This protocol and card set were frozen while the single-tool inference process was running. No single-tool model replies or outcomes were inspected before freezing. No catalogue replies yet existed.
