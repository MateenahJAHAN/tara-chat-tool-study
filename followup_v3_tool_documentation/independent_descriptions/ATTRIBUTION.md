# Sources and changes

The external function descriptions, schemas and questions are from *The Berkeley Function Calling Leaderboard*, Shishir G. Patil, Huanzhi Mao, Fanjia Yan, Charlie Cheng-Jie Ji, Vishnu Suresh, Ion Stoica and Joseph E. Gonzalez (ICML 2025). The authors describe the live data as user-contributed. The data directory identifies Apache 2.0. [Paper](https://proceedings.mlr.press/v267/patil25a.html) · [Pinned data README](https://github.com/ShishirPatil/gorilla/blob/6ea57973c7a6097fd7c5915698c54c17c5b1b6c8/berkeley-function-call-leaderboard/bfcl_eval/data/README.md) · [Data and answer files](sources.json).

We selected tool-positive examples from *When2Call*, Hayley Ross, Ameya Sunil Mahabaleshwarkar and Yoshi Suhara (NAACL 2025). NVIDIA releases that dataset under CC BY 4.0. We aligned the source IDs, compared question and description wording, and used BFCL v4 for the exact schemas and accepted argument values. The two releases share BFCL cases. [Paper](https://aclanthology.org/2025.naacl-long.174/) · [Dataset and license](https://huggingface.co/datasets/nvidia/When2Call).

In these experiments, catalogue reduction, optional function renaming, synthetic office metadata, and the instructions to the models were designed locally. Source text can contain spelling errors or outdated dates. All data and generated replies are local. The model checkpoints were Qwen2.5-1.5B-Instruct and SmolLM2-1.7B-Instruct. [Qwen](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct/tree/989aa7980e4cf806f80c7fef2b1adb7bc71aa306) · [SmolLM2](https://huggingface.co/HuggingFaceTB/SmolLM2-1.7B-Instruct/tree/31b70e2e869a7173562077fd711b654946d38674).
