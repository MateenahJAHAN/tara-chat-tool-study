# Do models call an irrelevant tool when it is the only one available?

Each source question receives its reference tool alone and, separately, each eligible distractor from that question’s own catalogue. Every pairing appears twice, first with its source name and once renamed lookup_function. All other fields and the question are identical across the two names. One-tool presentation, instructions and masking are interventions designed here. Questions, names, parameter schemas and top-level descriptions come from BFCL Live Multiple. Questions and function descriptions must match the independent When2Call tool-positive release verbatim. BFCL v4 is the reference for argument schemas and values. These are related dataset versions with common ancestry.

We select published consumer-information queries about movie, music, event, lodging, salon, attraction or weather searches, using the fixed function-name list in prepare.py. Two prompts that also explicitly request playback are excluded before inference. Previous TARA catalogue names, prior exact top-level descriptions and exact questions are excluded after case and punctuation normalization, using the manifests enumerated in sources.json. Inclusion is deliberately limited to these domains and to pairs with stable source wording. The unit for the primary comparison is the question, since one question can have several distractors.

The primary outcomes per model and naming condition are (1) fraction of target questions eliciting a correctly named call with an arguments object and (2) mean across questions of the fraction of distractor presentations eliciting a call attempt. Also report pooled counts, exact NO_CALLs, malformed/unclassified replies, and reference-argument matches (string comparison after stripping spaces and case, numeric values compared numerically; optional default-valued extras are allowed). A call attempt is structured JSON with a name or arguments, an explicit tool-call tag, or a leading call-like expression. Text without a recognizable call or exact NO_CALL is unclassified. Report a sensitivity interval if ambiguous outputs occur. Examine whether a distractor in the same upstream API namespace elicits more calls than a distractor in another namespace, restricted to questions with both. Masking differences are paired within the same question–tool combination. No inference about publication-level generality or independent training exposure follows from these selected examples.

Both pinned instruction checkpoints run locally, with their own chat templates and the same instruction, one tool per text catalogue, greedy decoding, a 96-token reply cap and batch size 12. Save all tokens and text. No tool is executed. Analyze only after both runs, with all eligible examples retained. No harm or capability metric depends on actually taking the simulated action.
