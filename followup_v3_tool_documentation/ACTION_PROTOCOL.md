# Does judging coverage predict the actual tool-use response?

Secondary paired experiment, November 21, 2026, New York. Specified after starting the block-14 experiment and before inspecting its output scores or running any free responses. Analyze all 256 unique tool, request, format, service and office combinations. Remove the letter classification instruction. Ask for an exact function call when the tool covers the request, otherwise NO_CALL. Use native tool-call syntax in the native condition and one JSON object in the inline condition. Keep the explanation of what the two district fields mean. Use the identical checkpoint and deterministic greedy decoding up to 72 new tokens. Save raw text, IDs and finish reason. No tool executions.

Measure recognized calls, correct function and complete exact arguments, explicit abstention, other output, and length caps. A response counts as an attempted call when it contains a tool-call opening tag, a JSON object bearing a name, or function-call syntax naming the displayed function. For native syntax the opening tag is sufficient for an attempt. Score the full output for exact semantic function and arguments, optionally wrapped by tool tags or code fences. Normalize case, spaces and underscores for the explicit NO_CALL count. Save unclassified outputs for inspection. Capped responses remain in all denominators.

For each format show in-scope exact calls and out-of-scope call attempts. On conflicting cards (the service and office disagree), report both. Across each format compare the sign of the average of the two A/B margins with the actual attempt outcome for the same card, including all 128 cards regardless of formatting. Report how many out-of-scope attempts also followed a correct two-letter judgment. As the prompts ask different questions, a discrepancy cannot locate a mechanism or establish that the model would spontaneously apply the rule. Both paradigms use fictitious services. No natural-frequency, security or healthcare claim.
